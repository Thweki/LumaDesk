测试使用隔离目录、真实只读查询和注入回调，不发送硬件调整命令。模式验证使用 CDS_TEST，排列使用 SDC_VALIDATE。实时拖动检查确认 DragCompleted 之前进入控制回调，慢请求期间滑块仍可操作。

0.3.1 定位回归覆盖 100%–300% 几何边界、负坐标工作区、小屏裁限，以及测试窗口跨真实混合 DPI 屏幕移动后触发 WPF DPI 变化并返回原停靠屏幕。拖动请求未完成时也验证定位修正不重建滑块。测试没有修改系统 DPI；不将跨屏窗口 DPI 通知等同于完整的显示器缩放写入验证。

布局图像由 WPF RenderTargetBitmap 产生，不能证明真实桌面磨砂像素效果。磨砂使用 DWM Desktop Acrylic，透明度关闭或接口不可用时回退实色。

五种语言的主界面与快捷面板截图已检查。应用图标包含九种 ICO 尺寸，托盘黑白渲染的透明轮廓一致。测试没有修改真实 Windows 主题注册表；实时主题切换仍需人工观察。语言切换设计为重启生效，不在正在执行显示操作时切换会话语言。系统原生错误消息沿用 Windows 提供的语言。
