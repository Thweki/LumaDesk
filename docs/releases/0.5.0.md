# LumaDesk 0.5.0 Preview

选屏更直观，多屏亮度一起调。这次也补齐了三种下载方式。

- 按桌面布局点选屏幕，亮度和缩放常驻，其他设置按需展开。
- “联调亮度”可多选或全选屏幕，只调整选中的设备。
- 改进部分显示器的输入源编码兼容，切换后读回确认结果。
- 保留场景预设、快捷键、HDR / ICC、屏幕排列和虚拟屏幕管理。
- 重写中英文 README，更新截图，加入真实界面的交互动图。
- GitHub Actions 自动测试、构建 EXE / portable ZIP / MSI，并生成 SHA-256 校验文件。

## 下载

| 文件 | 用法 |
| --- | --- |
| `LumaDesk-0.5.0-win-x64.exe` | 直接运行，免安装 |
| `LumaDesk-0.5.0-portable-win-x64.zip` | 解压后运行 `LumaDesk.exe`，含完整说明和许可 |
| `LumaDesk-0.5.0-win-x64.msi` | 安装到 Program Files，创建开始菜单快捷方式，需要管理员权限 |
| `SHA256SUMS.txt` | 上述三个文件的 SHA-256 校验值 |

Windows 10 / 11 x64，自带 .NET 运行时。三种版本共用 `%LOCALAPPDATA%\LumaDesk` 设置；MSI 卸载保留设置。EXE 和 MSI 暂未代码签名。

仍为预览版：HiDPI 使用 Windows 每屏缩放，不是全桌面超采样。硬件功能依赖显示器和驱动，验证范围见 [验证记录](https://github.com/Thweki/LumaDesk/blob/v0.5.0/docs/validation.md)。GIF 使用真实控件和模拟亮度写入，不代表硬件响应速度。

## English

Spatial screen selection, brightness adjustment for selected displays, and verified input switching. The rewritten READMEs include current screenshots and animated UI demos.

Choose the standalone EXE, the portable ZIP with documentation, or the MSI installer with a Start menu shortcut. Windows 10 / 11 x64; .NET is included. The MSI requires administrator access. All editions share settings in `%LOCALAPPDATA%\LumaDesk`; uninstalling keeps them. Binaries are currently unsigned.

Built and checked by GitHub Actions. SHA-256 checksums are included. Hardware compatibility is still being validated. Licensed under GPL-3.0-only; third-party licenses are included in the ZIP and MSI.
