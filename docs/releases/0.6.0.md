# LumaDesk 0.6.0

快捷面板现在用整行滑杆调亮度。点右上角的「⋯」，就能联调多块屏幕、定位显示器，或在布局图和带名称的屏幕列表之间切换。

- **显示预设**支持搜索、重命名、添加备注和 JSON 导入导出。可以把预设只应用到一块屏幕，也可以从托盘切换预设。
- **屏幕排列**支持相对定位。先选参照屏，再指定上下左右和对齐方式。预览里的编辑支持撤销和重做，确认后再应用。
- **诊断**新增 `--inventory` 显示器清单和 `--export-log` 本地日志导出，方便反馈硬件兼容问题。
- **应用设置**移除了“关于”页面。开机自启可让 LumaDesk 在登录后驻留托盘；新增的自动更新默认关闭。开启后会检查包括预览版在内的新版，下载并校验后在退出时安装。

已使用早期 0.6.0 的用户可重新下载对应的文件。使用 MSI 安装的用户可直接运行新版 MSI，保留原有设置。

## 下载

适用于 Windows 10 / 11 x64。四种下载共用已有设置。MSI 卸载时保留设置。

| 文件 | 适用场景 |
| --- | --- |
| `LumaDesk-0.6.0-win-x64.exe` | 直接运行，内置 .NET 运行时 |
| `LumaDesk-0.6.0-slim-win-x64.exe` | 下载体积最小，需已安装 x64 .NET 8 Desktop Runtime |
| `LumaDesk-0.6.0-portable-win-x64.zip` | 需要离线文档和许可，解压后运行 |
| `LumaDesk-0.6.0-win-x64.msi` | 需要开始菜单快捷方式和系统卸载入口，安装需管理员权限 |

`SHA256SUMS.txt` 提供以上四个文件的校验值。EXE 和 MSI 目前均未签名。

## English

The quick panel now has a full-width brightness slider. Open the ⋯ menu to link brightness across displays, identify a monitor, or switch between the display map and a named list. Presets support search, renaming, notes, JSON import and export, and single-display application. The layout editor adds relative positioning and undo/redo before applying changes. Use `--inventory` to inspect connected displays and `--export-log` to save a local log archive.

Choose the standalone EXE to run directly, the portable ZIP for offline documentation, or the MSI for a system-wide installation. The new slim EXE is the smallest download and requires the x64 .NET 8 Desktop Runtime. All four downloads use the same settings. SHA-256 checksums are included.

This refresh removes the About page. Under Settings → Application you can start LumaDesk in the tray at sign-in and opt in to automatic updates. Updates are off by default. When enabled, LumaDesk downloads and verifies new releases, including previews, and installs them on exit. If you already use the earlier 0.6.0 build, download your edition again. MSI users can run the refreshed installer over the existing installation.
